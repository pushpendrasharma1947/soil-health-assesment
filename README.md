# Machine Learning-Based Soil Health Assessment & Personalized Fertilizer Recommendation System

**Domain:** Precision Agriculture / Machine Learning  
**Algorithm:** Random Forest Classifier  
**Interface:** Streamlit Dashboard  

---

## 📁 Project Structure

```text
Soil_Health_Project/
│
├── soil_data.csv               # 200 sample agronomic dataset (N, P, K, pH, Moisture, Temp, Humidity, etc.)
├── train_model.py              # Training script: trains 2 Random Forest models strictly using the 7 PPT features
├── app.py                      # Interactive Streamlit dashboard with graphical charts & dosage advice
├── rf_soil_health_model.pkl    # Serialized Soil Health model (generated by train_model.py)
├── rf_fertilizer_model.pkl     # Serialized Fertilizer Recommendation model (generated by train_model.py)
├── requirements.txt            # Required Python packages
└── README.md                   # Project documentation
```

---

## 🚀 Quick Start Guide (How to Run in VS Code)

### Step 1: Open in VS Code
1. Unzip `Soil_Health_Project.zip`.
2. Open VS Code, click **File > Open Folder...**, and select the extracted `Soil_Health_Project` folder.

### Step 2: Install Dependencies
Open the VS Code Terminal (`Ctrl + ~`) and run:
```bash
pip install -r requirements.txt
```

### Step 3: Train the Models (One-Time)
Run the training script to train both Random Forest models:
```bash
python train_model.py
```
*Outputs:*
* `rf_soil_health_model.pkl` (Soil Health: Good / Moderate / Poor)
* `rf_fertilizer_model.pkl` (Fertilizer: Urea / DAP / MOP / NPK / No Additional Fertilizer)

### Step 4: Launch the Interactive Web Dashboard
Run the following command in the terminal:
```bash
streamlit run app.py
```

A browser window will open automatically displaying the live interactive dashboard!

## 🔬 Core Features & PPT Alignment
1. **7 Core Parameters:** Nitrogen (N), Phosphorus (P), Potassium (K), Soil pH, Soil Moisture, Ambient Temperature, and Ambient Humidity.
2. **Dual Model Architecture:**
   * Model 1: Assesses overall Soil Health Status.
   * Model 2: Prescribes the exact personalized fertilizer and dosage.
3. **Agronomic Remediation:** Lime recommendations for acidic soil and Gypsum for alkaline soil.
4. **Visual Analytics:** Interactive Plotly bar and radar charts comparing field values to ideal benchmarks.
5. **Exportable Advisory Report:** One-click download of the generated soil card.
